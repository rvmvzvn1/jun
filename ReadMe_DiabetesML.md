# Diabetes Prediction using Machine Learning

This project uses Machine Learning models to predict diabetes based on medical data.

## Project Overview
The notebook compares different Machine Learning algorithms for diabetes prediction and evaluates their performance.

## Technologies
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## Features
- Data preprocessing
- Machine Learning classification models
- Accuracy comparison
- Model evaluation

## Models Used
- Logistic Regression
- Decision Trees
- Random Forest
- Support Vector Machine

## Results
- Prediction accuracy
- Model comparison
- Classification analysis

## Files
- `diabetes_ml_models.ipynb` — Main notebook for diabetes prediction
